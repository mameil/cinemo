### 확정된 UI 결정
1. **지역 선택 UI 없음** — v1 홈은 크롤 대상 전역을 그대로 표시(헤더에 `파주·일산·고양·서울 서부 · 21개 지점` 라벨만). → 기존 D4(지역 프리셋) **폐기**, `regions.ts`는 v2 보류.
2. **홈 기본 뷰 = 영화별 묶기** (858회차 → 32줄). 각 줄: 포스터 + 제목 + `N회차` + 특전 종류 칩 + 지점 요약 + 다가오는 시간 칩 스트립. → 기존 D1 갱신.
3. **시간순 평면 리스트 = 토글** ("곧 시작 순"). 상단 `[영화별|시간순]` 세그먼트로 전환.
4. **기본 필터 `🕒 지금 이후`** — 이미 지난 회차 숨김(기본 ON).
5. **좌석 = `잔여/총` 그대로 노출** + 임박·매진만 색 강조(임박=주황, 매진=빨강, 여유=담백). 상태 배지 대신 숫자 유지.
6. **체인 색 구분** — CGV=빨강 / 롯데=주황 / 메가=보라. 카드 좌측 바 + 지점명 앞 점 + 필터칩.
7. **포스터 썸네일 홈에도 노출** (작게). 없으면 🎞️ 빗금 플레이스홀더 폴백.
8. **특전 종류 배지** — 홈엔 풀 이벤트명 대신 굿즈 종류(TTT/포스터/OT/현장이벤트…)만, **최대 2개 + `+N`**. 풀 목록은 상세.
9. **상세 진입** = 홈 카드/영화줄 탭 → 영화 상세. 상세엔 포스터 **항상** 연동.
10. **소진현황 = 게이지**. CGV는 실수치(`42/500`) 비율 게이지. **롯데·메가는 수량 미제공 → 상태(보유/소량/소진)→근사 채움** + "수량 미제공" 주석.
