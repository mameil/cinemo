# 특전 노출 규칙 (핵심 도메인 규칙)

> 2026-07-17 확정. 특전 관련 모든 기능(배지·미리보기·상세·향후 알림)의 판단 기준.
> 구현: `apps/web/src/lib/event-rules.ts` + `apps/web/src/app/api/screenings/route.ts`

## 판단 모델

**1차 리스트는 시간표다.** 영화·시간별 상영 회차(영화 × 극장 × 날짜)를 먼저 리스트업하고,
각 회차에 대해 이벤트를 대조해서 **"이 회차를 보면 이 특전을 받을 수 있다"가 성립할 때만** 노출한다.

"영화에 특전이 있다"(영화 단위)가 아니라 **회차 단위 성립 판정**이다.

## 성립 조건 (전부 AND)

| # | 조건 | 판단 근거 (데이터) |
|---|---|---|
| ① | **극장 부합** — 이벤트 진행 극장에 그 지점이 포함 | `goods_stock`의 지점 목록 = 이벤트 페이지 "진행 극장". 소진 지점도 진행 극장엔 포함(이벤트는 진행 중) |
| ② | **기간 부합** — 이벤트 기간 내 + **획득 조건이 열려 있음** | `events.start_date ≤ 기준일 ≤ end_date`. 단 DB 기간은 "수령 기간"이라, 얼리버드/선예매/사전예매는 **개봉일 이후 획득 불가** → 개봉일 지난 영화면 숨김 (`event-rules.ts isObtainable`) |
| ③ | **재고 있음** — 그 지점에서 소진 아님 | `goods_stock.status != '소진'` (배지 기준. 미리보기의 진행 극장 판정은 소진 포함) |
| ④ | **포맷 부합** — 포맷 전용 특전은 그 포맷 상영에만 | 이벤트명의 포맷 토큰(4DX/IMAX/SCREENX·SX/돌비/MX4D) → 상영 `format` 대조 (`event-rules.ts requiredFormat/formatSatisfies`). "4DX 포스터"는 4DX 회차에만 성립 — 2D 회차에 포스터 배지가 붙던 버그(호프×영등포)의 원인 |

## 미확인 이벤트 정책 (2026-07-17 결정)

진행 극장/재고 데이터가 아예 없는 이벤트(롯데 일부, 메가 MD 런칭 등)는
**노출하되 "지점 미확인" 표기** (`theaterIds: []` → EventPeek에 뉴앙스 칩).
정보 손실 없이 보여주되, 확정 정보가 아님을 드러낸다.

## 실제 사례 (규칙이 잡아낸 버그)

- **돌비 포스터 × 백석벨라시타** — 돌비관 전용(진행 극장 16곳) 이벤트가 돌비관 없는 지점 미리보기에 노출 → 조건① 위반. 진행 극장 필터로 해결
- **호프 얼리버드 × 7/17** — 개봉(7/15) 후엔 얼리버드 예매 불가인데 수령 기간(~7/28) 때문에 노출 → 조건② 위반. 개봉일 규칙으로 해결
- **호프 OT 전 지점 소진** — 소진 필터 때문에 진행 극장이 0곳으로 오판 → ①과 ③의 판단 근거를 분리해 해결

## 알려진 한계 (조건 ④ 관련)

- 포맷 판별은 이벤트명 키워드 휴리스틱 — 이름에 포맷이 없는 특수 조건(예: "언택트톡 엽서"=특정 회차 전용 GV)은 포맷 무관으로 취급되어 전 회차에 노출됨
- 상영 `format`이 비어 있으면 포맷 전용 특전은 미성립 처리 (보수적)

## 알려진 한계 (조건 ② 관련)

- 얼리버드 판정은 이벤트명 키워드(`얼리버드|선예매|사전예매`) 휴리스틱 — 획득 조건이 본문 이미지 안에만 있어 구조적 판별 불가
- "N차 관람" 등 조건부지만 여전히 획득 가능한 유형은 노출 유지 (의도됨)
- 개봉일 미상(KOBIS 백필 전) 영화의 얼리버드는 미개봉 취급 → 노출 유지, 백필되면 자동 제외
