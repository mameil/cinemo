# 하네스 구축 로그

이 프로젝트의 목적 중 하나는 **Claude Code 하네스(harness) 구축**이다.
반복 작업·수작업을 자동화 가능한 형태(슬래시 커맨드 · hook · 스크립트 · 권한 · 문서)로 전환한 기록을 여기 모은다.

> 새 세션에서 반복 패턴이나 자동화할 만한 마찰을 발견하면 → **후보**에 추가하고 사용자에게 기록 여부를 물어본다.
> 결정되면 채택/기각으로 옮기고, 채택한 건 실제로 구축한다.

> **분류 기준 (2026-07-18 정리)**: 하네스 = **도구(Claude Code)의 동작을 바꾸는 장치**
> (지시·권한·커맨드·훅·스크립트). 도메인 지식/스펙은 하네스가 아니라 **프로젝트 규칙** —
> `docs/`에 두고 여기선 이관 기록만 남긴다.

## 후보 (제안됨 · 미결정)

- [ ] **`/crawl-dry <source>`** — 개별 소스 dry-run(`--dry --max=3`)을 한 커맨드로. 지금은 `pnpm --filter @cinemo/crawler <source> -- --dry --max=3`를 매번 손으로 침.
- [ ] **매 실행 결과 알림 (데이터 레벨)** — 크론 성공/건수까지 webhook 통지. (PROJECT-STATUS의 희망사항)
- [ ] **DB 임시 조회 스크립트** — 07-18 세션에서만 `_tmp-*.ts` heredoc 생성→dotenv 실행→삭제를 15회 이상 반복. `packages/crawler/scripts/db-query.ts "SELECT ..."` 한 줄로 대체 가능. (효과 최대 후보)
- [ ] **dev 서버 기동 루틴** — 세션마다 서버 띄우기+포트 충돌 정리+에러 감시 수동 반복 (07-18: 이전 세션 서버 잔존으로 기동 실패 사례). 스크립트 또는 CLAUDE.md 절차화.

## 채택됨 (도구 하네스 — 구축 완료)

- ✅ **CLAUDE.md** — 매 세션 재발견하던 크롤러 실행 주문·모노레포 구조·플래그 관습·컨벤션을 고정. (`835f98a`)
- ✅ **권한 목록 정리** — `settings.local.json` 104→34개. 개별 크롤/tsx 실행을 와일드카드로 통합, 하드코딩 API 키(카카오·KOBIS) 제거.
- ✅ **GitHub Actions 워크플로우 이름 직관화** — `crawl`→`Crawl goods & movies (3h)`, `schedule`→`Crawl showtimes (daily)`. (`be74968`)
- ✅ **커밋 전 기록 컨펌 규칙** — 사용자가 커밋/푸시를 요청하면 ① 작업 로그 기록 여부를 묻고 ② 기록 문구를 보여준 뒤 컨펌받고 커밋한다. CLAUDE.md 지시로 박제. (2026-07-18)
- ✅ **타입체크 filter 강제** — 쉘 cwd 유지 특성 탓에 `cd 후 tsc`를 엉뚱한 디렉토리에서 돌려 가짜 에러 수백 줄을 만난 사고가 한 세션에 3회. `pnpm --filter @cinemo/web exec tsc --noEmit`(cwd 무관)로 CLAUDE.md에 박제. (2026-07-19)
- ✅ **장기 실행은 nohup으로 세션 분리** — 상상마당 시드(80건, 20~40분)를 세션 백그라운드로 돌리다 터미널 종료와 함께 9건째에서 사망, 예약해둔 "완료 후 커밋·푸시"도 증발 (2026-07-25). 10분 넘는 작업은 `nohup ... > 로그파일 2>&1 &`로 세션과 분리하고 로그 파일로 진행을 확인하도록 CLAUDE.md에 박제. Actions `workflow_dispatch`로 옮기는 대안은 현재 Actions 사용 불가 상태라 보류. (2026-07-25)

- 📄 **특전 노출 규칙** — [docs/특전-노출-규칙.md](특전-노출-규칙.md). 회차 기준 ①극장 ②기간(획득 가능) ③재고 ④포맷 AND 판정. CLAUDE.md 필독 링크로 연결 (링크 장치는 하네스, 내용은 프로젝트 규칙).

## 기각됨 / 보류

- ❌ **읽기전용 명령 추가 allowlist** — 자주 쓰는 명령(`cd`/`ls`/`cat`/`grep`/`git status·log·diff`)은 이미 자동 허용, `curl`/`node`/`npx`는 안전한 와일드카드 불가(임의 네트워크·코드 실행). 새로 넣을 게 없음.
- ⏸ **Stop hook로 세션 종료 시 하네스 상기** — 세션을 자주 열어 상금(노이즈) 우려. 일단 CLAUDE.md 소프트 지시로만.
