# 감상 카드 구상 (영화·드라마·책 기록)

> 2026-07-21 세션에서 정리. cinemo 본체와는 별개의 사이드 구상이지만,
> 포스터 소스(TMDB)·특전/티켓 문화 등 cinemo 자산과 자연스럽게 이어진다.

## 고민의 출발

- 영화·드라마·책을 보고 **왓챠피디아에 한줄평만** 남기고 있음 → 아쉬움
- 원하는 것: 짧게 몇 줄이라도 **어디서 봤는지, 디테일한 감정**까지 남기는 기록.
  "의미있게 남기고 싶다"
- 추가 욕구: **익명으로, 오픈된 곳에** 쓰고 싶음 (공개 상태가 주는 기록 동기 + 가벼운 교류)

## 결정된 방향

1. **왓챠피디아는 유지** — 한줄평+별점은 색인 역할
2. **원본은 마크다운으로 소유** — 플랫폼 종속·서비스 종료 리스크 회피.
   (git 관성이 있으니 journal 레포가 자연스러움)
3. **발행 채널 = 인스타 익명 부계정** — 영화·드라마·책 모두 커버, 부계 문화 자연스러움,
   티켓·특전 사진과 궁합. 글카드(이미지)로 변환해 캐러셀 업로드
4. 흐름: `md 작성(원본) → 스크립트로 카드 PNG 생성 → 인스타 수동 업로드(1분)`
   - 완전 자동 게시(API)는 비즈니스 계정 필요 → 익명 부계엔 과함. 생성만 자동화

## 저작권 검토 요약

- 포스터·표지는 저작물. 무단 업로드는 원칙상 복제·전송이나,
  **비평·리뷰 인용**(저작권법 28조)은 ①내 글이 주 ②출처 명시 ③원형 유지 시 방어 가능
- **블러의 역설**: 어설픈 블러 = 변형(동일성유지권 이슈 추가)이라 오히려 불리.
  단 **식별 불가 수준의 극강 블러**는 저작물의 표현이 남지 않아 안전 (= 색 팔레트 사용과 동일)
- 실무 리스크: 비상업 감상 계정은 관행상 매우 낮음 (권리자에게 홍보성).
  단 수익화·왜곡·조롱은 금물
- **안전 레이아웃 원칙**: 포스터 "위에" 글을 얹지 않는다 → 포스터는 원형 그대로 작게 + ⓒ출처,
  글은 분리된 영역에. 배경은 극강 블러 또는 추출 색

## 카드 디자인 후보 (1080×1350, 인스타 4:5)

(포스터 이미지는 미커밋 — 아래 "이미지 재수급" 참고)

| 버전 | 컨셉 | 예시 작품 | 특징 |
|---|---|---|---|
| **A. 블러+센터** | 극강 블러 배경 + 원형 소형 포스터 + 하단 감상 | 호프 | 포스터 색이 카드 전체 분위기를 지배. 무난한 감성 |
| **B. 매거진** | 밝은 지면, 포스터 좌측(오프셋 그림자), 드롭캡 | 2001 스페이스 오디세이 | 에디토리얼·잡지 스크랩 느낌. 재관람 기록과 어울림 |
| **C. 티켓 스텁** | 절취선·바코드·DATE/WHERE/PROGRESS/BONUS 칸 | 동궁 (드라마) | **특전 헌터 정체성과 최적** — BONUS 칸에 받은 특전, 드라마는 WHERE=넷플릭스·PROGRESS=EP, 구조화된 메타가 기록으로도 가치 |
| **D. 미니멀** | 포스터 추출 단색 배경, 표지는 우표 크기, 문장이 주인공 | 작별하지 않는다 (책) | 글 중심. 책 감상과 가장 잘 맞음. 저작권상 가장 안전 |

### 열린 선택지

- 한 템플릿으로 통일 (계정 일관성) vs **매체별 템플릿** (영화=C/A, 드라마=C 변형, 책=D)
- 블러 강도·포스터 크기·텍스트 정렬은 생성기 파라미터로
