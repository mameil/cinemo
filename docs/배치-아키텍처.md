# 배치 아키텍처 (2026-08-09 재정리)

> 세션 중 덧대며 지저분해진 배치/어드민을 **요구사항대로 깨끗이 재구성**하기 위한 단일 기준 문서.
> 작동하는 크롤러 로직·웹 화면은 유지하고, 오케스트레이션·어드민·소스 배정만 정리한다.

## 원칙

1. **상영시간표 = 공식 예매처 API에서** (Dtryx·MOVIEE·TinyTicket·체인 자체). 클라우드에서 수집 — 안 막힘.
2. **체인 굿즈 = 각 사 이벤트 페이지에서** (CGV·롯데·메가). 클라우드.
3. **독립관 굿즈 = 인스타에서** (로컬 필수 — 인스타만 IP 차단당함).
4. **인스타는 굿즈·소진·새 영화소식 전용.** 상영시간표는 절대 인스타에서 받지 않는다.

## 배치 구성

### 클라우드 (GitHub Actions)

- **상영시간표** (`schedule.yml`, 매일 1회):
  - 체인: cgv / lotte / megabox schedule
  - Dtryx: 라이카·모모·더숲·아리랑·씨네큐브·에무
  - MOVIEE: 필름포럼·상상마당·KU
  - TinyTicket: 서울아트·인디스페이스·아트나인 (**조사/미구현** — 되면 이관, 안 되면 자체사이트/보류)
  - 썸네일: TMDB(감독 대조) → Dtryx `Url` → MOVIEE `THUMB` 폴백
- **체인 굿즈** (`crawl.yml`, 3~4시간): CGV·롯데·메가 이벤트 페이지 → 특전 → 상영/영화 매칭

### 로컬 (개인 PC)

- **독립관 굿즈** (인스타, 하루 2~3회): 12계정 → 이벤트·굿즈·소식 → 상영/영화 매칭
  - IP 차단 완화: 계정을 그룹 분할(부하 분산) + 저빈도 + 조기중단. (프록시 필요 시 Apify 폴백)

## 어드민 (`/admin`)

- **배치별 현황 + 마지막 결과** (crawl_runs 기반)
- **수동 실행 버튼**:
  - 클라우드 배치 → GitHub `workflow_dispatch` (즉시). 서버 라우트 + PAT(Vercel env).
  - 로컬 배치 → DB "실행 요청" 플래그 → 로컬이 폴링해 곧 실행 (준실시간).
